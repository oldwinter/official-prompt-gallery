Record notes

A comparison with its limits attached.

Sampling

Each official prompt is run once through each route. The four cells are qualitative observations, not a benchmark score or a claim about general model quality.

Capability alignment

Both requests use 5 seconds and 16:9. MiniMax-H3 targets a 768 px short edge; the Grok route exposes a 480p preset. Their pixels and serving paths are not identical.

Identity and cost

Requested model names belong to the route. Served identity, seed, and cost are recorded only when the run exposes evidence; otherwise the ledger names the absence.

Publication boundary

Generation state, raw responses, credentials, and originals remain private. Only reviewed, hashed web derivatives and sanitized receipts enter this repository.
